# 商品計測・商品モニタリングの操作

商品計測と商品モニタリングを操作する人向けの手順。開発環境ではホストのリポジトリルートから起動する。仕様と制約は[商品計測と商品相場](../product-monitoring.md)を参照する。

## 操作

1. [ローカル開発](../../development/index.md)に沿って起動・DB準備する。
2. `/product-crawl-results` の「商品計測設定を追加」または各設定の「…」メニューの「編集」でモーダルを開き、名前と検索語・サイトを入力する。カテゴリなどは追加の検索結果URLでも指定できる。検索語とサイトは両方必要で、追加URLだけの登録もできる。「複製」では元の設定値を入れた登録モーダルが開く。メルカリの `/search?...`、イオシスの `/items?...`、じゃんぱらの `/sale/search/result/?KEYWORDS=...`、Yahoo!フリマの `/search/<キーワード>`、ヤフオクの `/search/search?...` と `/closedsearch/closedsearch?...`、トレファクの `/search?...` が対象。各URLの横にホスト名から判定したサイトを表示する。
3. 必要なら全検索共通の必須語・除外語・価格帯を設定する。更新モーダルでは、除外した出品を画像・名前・商品ページへのリンクつきで、件数を示して折りたたんで表示し、その場で個別に取り消せる。除外は `excluded_at` で表し、条件に一致する行は取得し直しても除外されたままになる。
4. モーダルの「登録」または「更新」で商品計測設定を保存する。
5. サイドバーの「商品計測」から `/product-crawl-results` を開く。商品計測設定ごとに新着8件のカードを横に並べ、カードの「…」メニューから出品を除外できる。設定名から `/product-crawl-results/:id` の詳細を開く。詳細では有効状態・サイト数・追加URL数・件数を表示し、販売状態の絞り込みと並び替えができ、「取得して保存」で非同期ジョブを投入する。しばらくしてから再読み込みすると保存結果を確認できる。カードの「…」メニューから出品を除外できる。一覧の「…」メニューと詳細の「設定を編集」で、商品計測設定の更新モーダルを開ける。
6. サイドバーの「商品モニタリング」から `/product-monitoring` を開き、名前・有効状態・必須語・除外語・価格帯を登録する。一覧では最安値、価格順の販売中商品（最大8件）と直近の平均購入価格を確認し、設定の編集・複製・削除ができる。設定名から詳細画面を開くと、条件に一致する販売中の商品を価格順に最大8件と、同じ条件の相場を表示する。詳細では出品の除外、直近30日の集計、7・14・30日の切り替え、条件の編集ができる。出品の除外は元の商品計測結果に反映される。


通知設定の項目は保存されるが、現行の通知判定はこの項目を参照しない。有効な商品モニタリング設定が通知評価の対象となる。
