# 日常操作

開発環境を操作し、必要時に本番の不具合を調査する開発者向けに、目的別の手順を案内する。アプリのコマンドはホストの対象 checkout のリポジトリルートから Docker Compose / just 経由で実行し、MCP の初回導入だけは端末で一度行う。

| 目的 | 手順 |
| --- | --- |
| ローカル環境の起動・状態確認・ログ確認・停止 | [ローカル環境の起動と状態確認](local-environment.md) |
| アプリの依存関係の更新・調査 | [依存関係の更新・調査](dependencies.md) |
| 本番障害のログ調査・MCP での接続時の確認 | [本番ログの調査](production-logs.md) |
| Claude Code・Codex・Cursor への初回ユーザー登録 | [本番ログ調査用 MCP のセットアップ](mcp-setup.md) |

初回の開発環境の準備は [初回セットアップ](../setup.md)、テストは [テスト](../testing.md)、環境の構成と接続先は [ローカル開発](../README.md) を参照する。
