# コーディング規約

Backend・Frontend・認証のコードを書く開発者と AI エージェント向けに、レイヤーに共通する書き方を定める。レイヤー固有の責務と規約は [Backend](backend/README.md)・[Frontend](frontend/README.md) を参照する。

## コメント

- コメントには、コードを読んでも分からない理由（外部仕様の制約、回避策、一見おかしく見える判断の根拠）だけを1行で書く。
- コードの言い換え、経緯・変更履歴、docs や PR 本文にある説明、セクションの区切り、使っていないコードのコメントアウトは書かない。

| 書く | 書かない |
| --- | --- |
| `# WAF（SiteGuard）が古い User-Agent を HTTP 500 で拒否するため、新しい User-Agent で取得する` | `# 送信できたら true を返す`（戻り値の言い換え） |
| `// 初期値には入力欄の maxLength が効かないため、name 列の上限 255 文字に収める` | `## associations ##`（セクションの区切り） |
