# Requirements Analysis Questions

## Q1. [プロダクト] 直す対象

依頼は、売り切れたじゃんぱらの商品が商品計測結果に販売中のまま残る不具合です。調査では、イオシスとトレファクも詳細取得（`fetch_detail`）が無く、保存する出品の `sold` は `false` です。この修正の対象を決めると、要件の範囲が決まります。

A. じゃんぱらだけを直す
B. じゃんぱらに加え、イオシスとトレファクも同じ不具合として直す
X. Other (please specify)

[Answer]: A. じゃんぱらだけを直す

## Q2. [プロダクト] 検索結果から消えた商品を売り切れにする条件

販売中の商品を誤って売り切れにしてはいけません。既存の個別確認は、そのサイトの取得が成功していること、最終更新から 3 時間以上たっていること、`sold` が true ではないこと、を条件にしています。じゃんぱらの検索は売り切れを載せず、今は消えた商品を更新しません。

A. じゃんぱらの検索取得が成功し、その結果に無い商品は、その時点で売り切れ（`sold: true`）にする
B. 取得が成功し、最終更新から 3 時間以上たっている商品だけを、結果に無いときに売り切れにする
C. 成功した検索に、続けて 2 回含まれない商品だけを売り切れにする
X. Other (please specify)

[Answer]: B. 取得が成功し、最終更新から 3 時間以上たっている商品だけを、結果に無いときに売り切れにする
