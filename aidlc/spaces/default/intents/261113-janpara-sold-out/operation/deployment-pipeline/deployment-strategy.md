# デプロイ戦略

この修正の出し方は、既存のイメージタグ更新と ArgoCD の同期である。新しい blue/green、canary、feature flag は足さない。ロールアウトの細目は `kuroweb/k8s` の既存マニフェストのままで、このリポジトリでは変えない。

## 環境

Integration が先、Production が後である。`develop` への push が Integration、`master` への push が Production を起動する。Production 用の別承認ワークフローは、この文書の範囲では足さない。全イメージをまとめて出すときだけ、各環境の `deploy-*.yml` を手動実行する。その経路は CI を含まないので、出す前に検証を済ませる。

## この修正

backend イメージだけが対象になる。データベースのマイグレーションは無い。`sold` の更新はアプリの保存処理だけで、スキーマは変えない。

## 機能フラグ

使わない。検索から消えたじゃんぱらを売り切れにする条件は、デプロイ後のコードがそのまま適用する。
