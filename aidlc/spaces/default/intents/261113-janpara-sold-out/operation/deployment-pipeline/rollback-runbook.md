# ロールバック

新しい戻し手順は足さない。CD が書いたイメージタグを、前のタグに戻す。

## 戻す手順

1. 対象環境（Integration なら Integration、Production なら Production）を決める。
2. `kuroweb/k8s` の `manifests/price-monitoring` で、その環境の backend イメージタグを、出す前のタグに戻す。
3. その変更を push する。
4. ArgoCD の同期で、クラスタが前のイメージに戻ることを確認する。

このリポジトリのコミットを revert しても、レジストリに残ったイメージと、k8s リポジトリのタグが前を向くまでクラスタは戻らない。タグの戻しが戻し操作である。

## データ

マイグレーションは無い。`sold` を `true` にした行や、検索結果に戻って `false` にした行は、戻したイメージの保存処理では自動では戻らない。タグを戻したあとも、その行の `sold` は戻した時点の値のまま残る。

## 確認

戻したあと、商品モニタリングの販売中一覧が、戻したイメージの判定で更新されることを見る。ヘルスチェック用の新しいエンドポイントは足さない。
