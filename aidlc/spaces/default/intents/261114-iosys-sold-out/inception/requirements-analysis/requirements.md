# 要件分析

## 目的

イオシスの検索から消えた商品が販売中のまま残る問題を、じゃんぱらと同じ方針で解消する。

## 機能要件

- **FR1**: イオシスの検索元が1件以上あり全件成功した場合、検索結果に含まれず最終更新から3時間以上経過した同一計測設定のイオシス商品を売り切れにする。
- **FR2**: イオシスの検索結果に戻った既存商品は販売中に戻す。価格がなく保存対象外の商品も検索結果への存在判定に含める。
- **FR3**: イオシスの検索元がない場合や1件でも失敗した場合、検索から消えたことを理由に売り切れへ変更しない。
- **FR4**: 他のサイトと他の計測設定の商品には、イオシスの消失判定を適用しない。じゃんぱらの既存動作も維持する。

## 非機能要件と制約

- **NFR1**: 既存の処理方式に沿い、売却日や更新日時を消失判定だけで変更しない。
- **NFR2**: 回帰テストを追加し、既存テストとともに Docker Compose の backend コンテナで検証する。
- デプロイは CI/CD と ArgoCD が担う。

## 前提と対象外

- じゃんぱらの現行実装を同じ方針の基準とする。検索ページの取得上限など既存の取得範囲は変更対象外とする。
- 個別の商品詳細取得、新しい画面、デプロイ作業は対象外。
